🌟 Overview & Purpose of THETRON

THETRON is an autonomous AI & Cloud Systems showcase engineered to demonstrate real-world, enterprise-grade engineering principles: zero-trust multi-persona Git governance, automated DevSecOps verification gates, in-browser semantic knowledge retrieval (RAG), and cost-avoidance FinOps engineering.

📐 Mathematical Genesis: Srinivasa Ramanujan Mock Theta Functions

The name THETRON fuses Theta (θ) and Neuron. It honors legendary Indian mathematician Srinivasa Ramanujan, whose final 1920 letter to G.H. Hardy unveiled Mock Theta Functions—mysterious mathematical functions that share asymptotic properties with modular forms while fundamentally resisting modular transformations. In neural systems, Ramanujan's theta mirrors how activation functions and non-linear transformers navigate complex semantic state spaces.

💰 The $0.00 Infrastructure Spend Invariant (Option C)

Traditional AI portfolios deploy continuous Cloud Run containers or GKE clusters, accumulating idle compute and egress bills of $58.40+/month. THETRON enforces an immutable $0.00 infrastructure spend invariant through Option C Decoupling:

  • Continuous Deployment Showcase: Packaged as a hybrid single-page application and distributed via GitHub Pages with global CDN edge caching.
  • Direct Client-Side GenAI: Google Gemini 3.6 Flash queries run directly from the browser over secure HTTPS, completely eliminating server bottlenecks.
  • Decoupled Container Pipeline: The enterprise FastAPI backend and Docker packaging remain fully maintained in repository source, triggering container builds only on designated production releases.

🛡️ Multi-Persona Git Governance & Bidirectional Separation of Duties

To prevent single-committer privilege escalation, THETRON implements strict Interpretation A governance with mutual exclusivity between Developer and Lead personas across 4 defense layers:

  • vign87a-dev: Feature author who crafts branches, commits changes, and opens pull requests using id_ed25519_dev. Strictly prohibited from self-approving or merging PRs.
  • vign87a-lead: Senior technical lead who enforces reviews, audits CI gates, and signs merges using id_ed25519_lead. Strictly prohibited from authoring commits, pushing feature branches, or opening PRs.
  • CI Governance Gate (governance-gate.yml): Automated workflow that validates PR and commit authors, rejecting any PRs created by vign87a-lead and enforcing mandatory approval from vign87a-lead.
  • GitHub CODEOWNERS (.github/CODEOWNERS): Designates @vign87a-lead as the required code owner for all files, disallowing self-approval by the author.
  • Automated PR Review Bot: Autonomous agent performing line-by-line diff inspection, security policy checks, and architectural validation before any PR merges.

🛠️ Operator Runbook: Local Setup & Execution

Follow this step-by-step runbook to reproduce the THETRON platform locally on Windows, macOS, or Linux.

1. Clone Repository & Configure SSH Identities

Configure separate SSH aliases in ~/.ssh/config to guarantee identity isolation:

# Developer Persona Host github-dev HostName github.com User git IdentityFile ~/.ssh/id_ed25519_dev # Lead Reviewer Persona Host github-lead HostName github.com User git IdentityFile ~/.ssh/id_ed25519_lead

2. Install Local DevSecOps Git Hooks

Activate local pre-commit and pre-push hooks to enforce bidirectional SoD locally:

# Windows PowerShell powershell -ExecutionPolicy Bypass -File .\scripts\setup-hooks.ps1 # Linux / macOS chmod +x scripts/setup-hooks.sh && ./scripts/setup-hooks.sh

3. Local Python Environment & Dependencies

# Create and activate virtual environment python -m venv venv .\venv\Scripts\Activate.ps1 # (Linux/macOS: source venv/bin/activate) # Install production and testing dependencies pip install fastapi uvicorn jinja2 google-genai pytest bandit

4. Run DevSecOps AST & Secret Scans Locally

# Run Pytest test suite python -m pytest tests/ -v # Run Bandit AST Security Scan (High & Medium Severity Gate) python -m bandit -r app/ -ll # Run TruffleHog Secret Scan (Docker or binary) trufflehog git file://. --only-verified

5. Run FastAPI Backend Locally

# Start local Uvicorn server with hot reload uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

Access the live dashboard locally at http://127.0.0.1:8000.
